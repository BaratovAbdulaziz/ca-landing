# Counter Arena features

## Workout features

| Feature                 | Short description                                     |
| ----------------------- | ----------------------------------------------------- |
| Push-up rep counting    | Counts completed push-ups through the phone camera.   |
| Squat rep counting      | Counts completed squats through the phone camera.     |
| Live rep counter        | Shows the current count during a workout.             |
| On-device pose tracking | Analyzes movement on the phone.                       |
| Tracking modes          | Lets users choose Standard or High accuracy tracking. |
| Exercise selection      | Lets users choose a movement before starting.         |
| Framing guidance        | Helps users position the phone and stay visible.      |
| Workout controls        | Starts, pauses, resumes, and ends a session.          |
| Rep feedback            | Gives a visual or audio cue when a rep counts.        |
| Workout summary         | Shows reps and duration after a session.              |
| Workout history         | Saves previous sessions for review.                   |
| Offline workouts        | Works without internet after model setup.             |
| Plank hold timer        | Measures a valid plank hold in seconds.               |
| Workout goals           | Sets a rep or time target for a session.              |
| Progress tracking       | Shows changes in activity and performance over time.  |
| Accessibility options   | Adds larger text and hands-free cues.                 |

## Competition features

| Feature                  | Short description                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------- |
| One-on-one challenge     | Two people compete on the same exercise and goal.                                     |
| Friend invitation        | One person sends a challenge link or invite to another.                               |
| Live match               | Both people exercise at the same time and see the score.                              |
| Asynchronous match       | Each person completes the challenge when available.                                   |
| Rep challenge            | For push-ups or squats, the winner completes the most valid reps within a time limit. |
| Plank hold challenge     | For planks, the winner holds a valid plank for the most seconds.                      |
| Competition rules        | Shows the exercise, time limit, scoring, and tie-breaker before starting.             |
| Valid movement and holds | Scores completed reps for push-ups and squats, and valid hold time for planks.        |
| Match result             | Shows both scores in reps or seconds and names the winner.                            |
| Rematch                  | Starts another challenge with the same person.                                        |
| Match history            | Saves previous one-on-one results.                                                    |
| Privacy controls         | Lets each person choose which profile and result details to share.                    |

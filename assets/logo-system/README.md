# Counter Arena logo system

Four arrangements of the same approved CA mark and Counter Arena wordmark:

1. `01-primary.svg` — horizontal mark and wordmark.
2. `02-secondary.svg` — stacked mark and wordmark.
3. `03-simplified.svg` — wordmark alone.
4. `04-submark.svg` — CA mark alone.

Each SVG embeds the same transparent source artwork from `../counter-arena-wordmark.png`. The athlete is a website character and is not part of the logo.
